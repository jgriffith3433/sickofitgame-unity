# Sick Of It — Architecture

## Core Philosophy
**The game IS the config.** One ScriptableObject (`GameDefinition`) defines every level, video, death scene, enemy, and player setting. Unity scenes are OUTPUT generated from this config. You edit the definition, press one button, the game regenerates.

## Scene Architecture

### Menu Scenes (in Build Settings, loaded directly)
| Scene | Purpose |
|-------|---------|
| MainMenu | Title screen, New Game / Continue / Quit |
| LevelSelection | Grid of unlocked levels |
| VideoSelection | Grid of unlocked videos |
| UpgradeShop | Spend points on upgrades |

### Game Scenes (loaded via Addressables, generated by ProjectGenerator)
| Scene | Runtime Bootstrap | Config Source |
|-------|-------------------|---------------|
| `Video.unity` | VideoRuntime | `GameDefinition.GetVideo(PlayerPrefs["CurrentVideoNumber"])` |
| `Level.unity` | LevelRuntime | `GameDefinition.GetLevel(PlayerPrefs["CurrentLevelNumber"])` |
| `Death.unity` | DeathRuntime | `GameDefinition.GetDeath(PlayerPrefs["CurrentDeathConfig"])` |

**These 3 scenes are identical shells.** They contain only a camera and basic GameObjects. The Runtime scripts auto-attach via `[RuntimeInitializeOnLoadMethod]` and build ALL content dynamically from config.

## Data Flow

```
Player Action (e.g. "New Game")
    ↓
MainMenuManager
    ↓
SceneTransitionManager.LoadVideo(1)
    ↓
Sets PlayerPrefs["CurrentVideoNumber"] = 1
Loads "Video" via AddressablesSceneLoader
    ↓
Video.unity loads
    ↓
VideoRuntime auto-bootstraps (scene.name == "Video")
    ↓
Reads PlayerPrefs["CurrentVideoNumber"] → 1
Reads GameDefinition.GetVideo(1) → VideoConfig
    ↓
Finds/creates VideoPlayer GameObject + SpriteFramePlayer
Initializes SpriteFramePlayer with VideoConfig.spriteFramesData
    ↓
SpriteFramePlayer loads sprite chunks via Addressables
Plays frames using Time.deltaTime (or GameClock)
    ↓
On completion → SceneTransitionManager.LoadLevel(config.nextLevel)
```

Same pattern for Level and Death scenes.

## Key Singleton Patterns
- **GameDefinition.Instance** — Loaded from `Resources/GameDefinition` at runtime
- **SceneTransitionManager.Instance** — DontDestroyOnLoad, handles all scene routing
- **GameClock.Instance** — Per-scene singleton, drives time for rewind system
- **GameProgressManager.Instance** — Save/load player progress
- **RogueliteManager.Instance** — Roguelite upgrade/health persistence

## Addressables System
- Sprite frame chunks are loaded via Addressable labels (e.g., `Video1_Part1`, `Level1_Background1`)
- Game scenes (`Video`, `Level`, `Death`) are Addressable with addresses matching their scene names
- `AddressablesSceneLoader` handles scene loading
- `AddressablesOperationManager` handles asset loading with memory management
- WebGL builds are memory-constrained — SpriteFramePlayer limits to 2 chunks max on WebGL

## Rewind System
- **GameClock** — Master time that can go forward or backward
- **StateRecorder** — Snapshots game state each frame
- **RewindController** — Holds rewind button → GameClock reverses → StateRecorder restores snapshots
- **SpriteFramePlayer** — Can optionally use GameClock.Time instead of Time.deltaTime (set `useGameClock = true`)
- **ExperienceRunner** — Fires timeline events based on GameClock time, works in both directions
